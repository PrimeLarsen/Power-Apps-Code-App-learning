# Exercise 2 — Edit UI and republish (20 min)

**Goal:** Prove that the local loop → publish cycle is faster than studio-based editing.

1. Your app is running in Power Apps (from exercise 1)
2. Make a visual improvement locally (e.g. a CSS file in `src/`, colors/card layout)
3. `npm run build && pac code push`
4. Check the updated version in Power Apps — how long did the full cycle take?

**Compare in plenum:** who went from "idea" to "live in Power Apps" fastest?
